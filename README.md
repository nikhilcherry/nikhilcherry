# Hi, I'm Nikhil

I build things end to end: hardware and firmware, ML pipelines, mobile apps and the glue between them. Student at NMIT Bengaluru. Most of my work comes out of 24 to 48 hour hackathons, and the ones below are the ones I would still show someone.

**Resume and selected projects: [nikhil-av.vercel.app](https://nikhil-av.vercel.app)**

## Featured projects

| Project | What it is | Stack |
| --- | --- | --- |
| [**assay**](https://github.com/nikhilcherry/assay) | Agentic fraud investigator on TigerGraph whose probabilities are measured, not guessed. Held-out AUC 0.964 against the bank's own 0.866. [Live replay](https://nikhilcherry.github.io/assay/) | Python, TigerGraph, scikit-learn |
| [**chaukanna**](https://github.com/nikhilcherry/chaukanna) | Live scam-call guardian. Whispers a warning only the victim hears, an AI agent cuts the scammer off, n8n files the evidence. Caught 28 of 28 scam calls with 0 false alarms on 19 ordinary ones | Flutter, LiveKit, Sarvam, n8n, Supabase |
| [**arvyo**](https://github.com/nikhilcherry/arvyo) | A star dims; was it a planet, an eclipsing binary, a blend or a starspot? Fits all four forward models from physics on TESS/Kepler light curves | Python, NumPy, PyTorch |
| [**connect**](https://github.com/nikhilcherry/connect) | Reach a car's owner through a QR tag without sharing phone numbers. 139 backend and 146 app tests | Flutter, Supabase |
| [**jitter**](https://github.com/nikhilcherry/jitter) | Find out *why* a test is flaky: twelve isolated sources of nondeterminism, statistical attribution, a repro that fails 10 out of 10 | Python, zero dependencies |
| [**strata**](https://github.com/nikhilcherry/strata) | Code archaeology: crosses git churn with code complexity to show where a repo's risk lives, in one HTML report | Python, zero dependencies |
